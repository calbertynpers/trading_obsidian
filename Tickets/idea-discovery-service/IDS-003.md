# IDS-003 — RSI Extreme Scanner

**Status:** 🔴 Open
**Priority:** Medium
**Component:** `idea_discovery_service` — automated symbol discovery
**Type:** Feature
**Reported:** 2026-05-01
**Depends on:** [[IDS-004]] (Marimo notebook generator), [[IDS-005]] (`LiveMCPDataProvider`)
**Feeds into:** [[IDS-004]] (triggers notebook generation), [[TIS-007]] (downstream)

## Summary

Hourly scheduled task that scans Binance perpetual futures for RSI extremes (≥ 70 or ≤ 30) and automatically generates a Marimo setup notebook for each flagged symbol. Sends a Telegram notification with the notebook path so the user can open it on desktop.

This is the automated trigger layer that feeds [[IDS-004]]. Without it, the user has to manually decide which symbols to analyse. With it, the system surfaces candidates proactively.

---

## Context

The IDS-002 POC proved that agent-generated Pine Scripts produce actionable setups (BTC profitable trade confirmed 2026-05-01). IDS-004 provides the interactive review notebook. This ticket closes the loop by automating the "which symbol should I look at?" question.

RSI extremes are a simple, well-understood signal for potential mean-reversion or fade-the-pump setups:
- RSI ≥ 70 → overbought → potential FTP (short) candidate
- RSI ≤ 30 → oversold → potential Mean Reversion (long) candidate

The scanner doesn't make trading decisions — it surfaces candidates for human review via the Marimo notebook.

---

## Requirements

### Scanner

- [ ] Scan all Binance USDT perpetual futures symbols (or a configurable watchlist subset)
- [ ] Use TradingView MCP `coin_analysis` (1h timeframe) to get RSI values
- [ ] Flag symbols where RSI ≥ 70 (overbought) or RSI ≤ 30 (oversold)
- [ ] For each flagged symbol, determine recommended setup type:
  - RSI ≥ 70 → `ftp` (Fade The Pump)
  - RSI ≤ 30 → `mean_reversion`
- [ ] Deduplicate: don't re-flag a symbol that was flagged in the last N hours (configurable, default 4h)

### Notebook generation

- [ ] For each flagged symbol, call `scripts/generate_notebook.py` with symbol, setup type, RSI value, and direction
- [ ] Collect the output notebook path

### Telegram notification

- [ ] Send a single Telegram message per flagged symbol via Telegram MCP:
  ```
  📓 Setup notebook ready: XYZUSDT (RSI 76.2, SHORT candidate)
  Open: ~/idea_discovery_service/setups/XYZUSDT-2026-05-01-1400.py
  ```
- [ ] If multiple symbols flagged in one scan, batch into a single summary message with individual notebook paths

### Scheduling

- [ ] Runs hourly (configurable interval)
- [ ] Implementation: agent-driven scheduled task (the agent runs the scan on a cron-like schedule)
- [ ] Graceful handling of MCP tool failures (skip symbol, log warning, continue scan)

### Configuration

- [ ] Configurable RSI thresholds (default: 70 upper, 30 lower)
- [ ] Configurable scan interval (default: 1 hour)
- [ ] Configurable dedup window (default: 4 hours)
- [ ] Configurable watchlist (default: all USDT perps, or a subset)
- [ ] Config stored in `config/rsi_scanner.yaml` or similar
