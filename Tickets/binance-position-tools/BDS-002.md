## Summary

Added `place_take_profit_order` MCP tool that places TAKE_PROFIT_MARKET conditional orders via the Binance Algo Order API (`sign_request("POST", "/fapi/v1/algoOrder")` with `type="TAKE_PROFIT_MARKET"` and `algoType="CONDITIONAL"`).

## Implementation

- `place_take_profit_order()` in `position_service.py` with parameter validation (side, quantity, tp_price, position_side)
- MCP tool wrapper in `position_mcp_server.py` with standard error handling
- No retry on write operations
