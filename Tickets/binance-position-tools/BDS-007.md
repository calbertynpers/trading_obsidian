# BDS-007: Add Modify/Amend Order Tool

**Priority:** High
**Status:** 🔴 Open
**Component:** `binance_data_collector.position_mcp_server`
**Reported:** 2026-04-22

---

## Summary

Add a `modify_order` tool that amends an existing order's price or quantity without cancelling and re-placing. Reduces race condition risk and is atomic.

## Parameters

```
symbol: str
order_id: int
price: float (optional)     — new price
quantity: float (optional)  — new quantity
```

## Binance API

- Standard orders: `PUT /fapi/v1/order`
- Algo orders: `PUT /fapi/v1/algoOrder`
- May need to handle both endpoints (like cancel_order does)
