## Summary

The `place_limit_order` MCP tool ignored the `price` parameter and placed orders at rounded prices. The `place_stop_order` tool used a deprecated endpoint.

## Root Cause (Confirmed)

1. **Price precision bug**: `round(price, 2)` hardcoded instead of using symbol's `pricePrecision` from exchange info.
2. **Stop-market endpoint bug**: `client.new_order()` with `type="STOP_MARKET"` rejected since Dec 2025 Algo Order API migration.

## Fix Applied

1. Added `_get_pair_price_precision()` helper, replaced hardcoded rounding with dynamic precision
2. Replaced `client.new_order()` with `client.sign_request("POST", "/fapi/v1/algoOrder", params)` for stop orders

## Production Verification

Placed 3 BASUSDT limit buy orders at $0.014, $0.012, $0.011 — all placed at exact specified prices with correct quantities. BDS-001 fix confirmed working.
