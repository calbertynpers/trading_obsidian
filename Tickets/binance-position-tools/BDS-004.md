## Summary

Fixed `get_open_orders` to also query the Algo Order API for conditional orders (STOP_MARKET, TAKE_PROFIT_MARKET).

## Endpoint Discovery

- `/fapi/v1/algoOrders` → 404 (doesn't exist)
- `/fapi/v1/allAlgoOrders` → requires symbol, returns all statuses
- `/fapi/v1/openAlgoOrders` → **correct**: returns only open/active orders, symbol optional

## Fix Applied

- Added query to `GET /fapi/v1/openAlgoOrders` inside `fetch_open_orders()`
- Added `_normalize_algo_orders()` helper for field mapping
- Graceful degradation on algo endpoint failure

## Production Verification

Before fix: 6 orders (LIMIT only). After fix: 13 orders (6 LIMIT + 7 STOP_MARKET).
