# BDS-012: Add Batch Orders Tool

**Priority:** Medium
**Status:** 🔴 Open
**Component:** `binance_data_collector.position_mcp_server`
**Reported:** 2026-04-22

---

## Summary

Add a `place_batch_orders` tool that places up to 5 orders in a single API call.

## Binance API

- Endpoint: `POST /fapi/v1/batchOrders` with `batchOrders` JSON array (max 5)
- For algo orders, may need individual `POST /fapi/v1/algoOrder` calls
