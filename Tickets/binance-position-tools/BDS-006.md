# BDS-006: Add Trailing Stop Order Tool

**Priority:** High
**Status:** 🔴 Open
**Component:** `binance_data_collector.position_mcp_server`
**Reported:** 2026-04-22

---

## Summary

Add a `place_trailing_stop_order` tool that places a TRAILING_STOP_MARKET order via the Algo Order API. The stop price automatically trails the mark price by a callback rate as price moves in the position's favor, locking in profits without manual adjustment.

## Parameters

```
symbol: str            — e.g. "NAORISUSDT"
side: str              — "BUY" or "SELL"
quantity: float        — order quantity
callback_rate: float   — callback percentage (e.g. 3.0 for 3%)
activation_price: float (optional) — price at which trailing starts
position_side: str     — "LONG", "SHORT", or "BOTH" (default "BOTH")
```

## Binance API

- Endpoint: `POST /fapi/v1/algoOrder` with `algoType="CONDITIONAL"`, `type="TRAILING_STOP_MARKET"`
- Uses `callbackRate` and optionally `activationPrice`
- Same pattern as existing stop and TP orders

## Use Cases

- NAORIS short at +16% — set trailing stop with 5% callback to lock in profits while letting it run
- Any position in profit — auto-trail instead of manually adjusting stops
