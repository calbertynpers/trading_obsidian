## Summary

Add a `get_balance_history` tool that tracks wallet balance over time. Useful for equity curve visualization, drawdown analysis, and portfolio performance.

## Binance API

- Current balance: `GET /fapi/v2/balance`
- Historical: derived from `GET /fapi/v1/income` by accumulating income events
