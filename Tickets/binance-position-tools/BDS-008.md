# BDS-008: Add Order History Tool

**Priority:** High
**Status:** 🔴 Open

**Reported:** 2026-04-22

## Summary

Add a `get_order_history` tool that queries filled, cancelled, and expired orders. Essential for P&L tracking, trade journaling, and understanding what happened while the agent wasn't watching.

## Binance API

- Standard orders: `GET /fapi/v1/allOrders` with `symbol` (required)
- Algo orders: `GET /fapi/v1/allAlgoOrders` with `symbol` (required)
- Should merge both for complete history
