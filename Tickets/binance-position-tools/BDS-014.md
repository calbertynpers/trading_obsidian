# BDS-014: Add Funding Rate & Open Interest Snapshot Tool

**Priority:** High
**Status:** 🔴 Open
**Component:** `binance_data_collector.position_mcp_server`
**Type:** Feature
**Reported:** 2026-04-22

---

## Summary

Add a `get_funding_info` tool that queries live funding rate, predicted next funding, next funding time, and open interest for one or more symbols on demand. Unlike the data collector's `get_snapshot` (which is watchlist-bound), this tool queries Binance public endpoints directly for any arbitrary symbol. No auth required.

## Problem

Today, funding rate data is only available for symbols on the collector's watchlist via `get_snapshot`. If a trader wants to check funding on a coin they don't track, or compare funding across all their held positions, there's no single tool that does this. Open interest — the context that makes funding meaningful — isn't collected at all.

## Binance API

- **Funding rate**: `GET /fapi/v1/premiumIndex` — returns `lastFundingRate`, `markPrice`, `nextFundingTime` for a single symbol or all symbols (public, no auth)
- **Open interest**: `GET /fapi/v1/openInterest` — returns `openInterest` and `symbol` (public, no auth, single symbol only)
- **Historical funding**: `GET /fapi/v1/fundingRate` — returns historical funding rate settlements with timestamps (public, no auth)

## Use Cases

1. **"What's BIO's predicted next funding?"** — Query premiumIndex for BIOUSDT, return current rate + next funding time
2. **"Show me funding across all my positions"** — Query premiumIndex for all active position symbols, rank by funding rate
3. **"Which of my coins have the highest funding cost?"** — Same as above, sorted by absolute funding rate
4. **"Show me funding + OI for NAORIS"** — Combined premiumIndex + openInterest query
5. **"Where did funding flip positive today?"** — Compare current funding rate against historical (requires fundingRate endpoint)
6. **Cross-coin funding screening** — Rank all held symbols by funding rate to identify crowded trades

## Proposed Interface

```python
get_funding_info(
    symbols: list[str] | None = None,  # None = all active positions
    include_open_interest: bool = True,
    include_history: bool = False,      # include last N funding settlements
    history_limit: int = 10,
)
```

## Acceptance Criteria

- [ ] Query premiumIndex for one or more symbols (or all active positions by default)
- [ ] Return: symbol, current funding rate, predicted next funding rate, mark price, next funding time, index price
- [ ] Optionally include open interest per symbol (separate API call per symbol)
- [ ] Optionally include last N historical funding rate settlements
- [ ] Rank/sort results by absolute funding rate (highest cost first)
- [ ] Include summary: count of positive/negative funding, highest/lowest rates, total estimated 8h funding cost across positions
- [ ] Public endpoints — no auth required, but still use retry logic
- [ ] Follow existing read tool patterns (error handling, response structure)

## Notes

- premiumIndex can return all symbols in one call (no symbol param = all), so the "all active positions" mode is efficient
- openInterest requires one call per symbol — may want to make it optional for large portfolios
- The `funding_rate` field from premiumIndex is the *predicted* next funding rate, updated in real-time
- `lastFundingRate` is the most recently settled rate
- Consider caching premiumIndex response briefly if multiple tools query it in the same session
