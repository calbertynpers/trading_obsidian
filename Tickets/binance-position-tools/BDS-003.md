## Summary

Added three MCP tools for reading and managing open orders. The agent can see ALL resting orders — limits, stops, take-profits, and conditionals — and cancel them programmatically.

## Production Verification

Called `get_open_orders()` — returned 13 orders (6 LIMIT + 7 STOP_MARKET) across 7 symbols. All order types, prices, quantities, and position sides correct. Algo/conditional orders visible after BDS-004 fix.

## Implementation

### `get_open_orders` (Read Tool)
- Queries both `GET /fapi/v1/openOrders` (standard) and `GET /fapi/v1/openAlgoOrders` (conditional)
- Returns orders grouped by symbol with AI-friendly summary
- Retry with exponential backoff (3 attempts)
- Graceful degradation on algo endpoint failure

### `cancel_order` / `cancel_all_orders` (Write Tools)
- Cancel specific order or all orders for a symbol
- No retry on write operations
