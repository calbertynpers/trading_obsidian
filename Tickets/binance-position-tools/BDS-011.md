# BDS-011: Add Countdown Cancel-All (Dead Man's Switch)

**Priority:** Medium
**Status:** 🔴 Open
**Component:** `binance_data_collector.position_mcp_server`
**Reported:** 2026-04-22

---

## Summary

Add a `set_countdown_cancel_all` tool — dead man's switch that cancels all orders if not refreshed within N seconds.

## Binance API

- Endpoint: `POST /fapi/v1/countdownCancelAll` with `symbol` and `countdownTime`
- Setting `countdownTime=0` cancels the timer
