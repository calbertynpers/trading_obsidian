# ADF-012: Deploy TIS Ingestion Pipeline to EC2

## Summary

Deploy the TIS ingestion pipeline (price fetcher, condition evaluator, webhook receiver, enrichment, SQS publisher) to the EC2 instance alongside the Binance Data Service. The pipeline runs as a systemd service, publishes enriched TriggerEvents to SQS.

## Architecture on EC2

```
/opt/trading/tis/
├── venv/                          # Python venv (uv, Python 3.14)
├── trigger_ingestion/             # Application code (git clone)
├── config/
│   └── tis.yaml                   # Production config (env vars for secrets)
├── logs/
│   └── tis-pipeline.log
└── scripts/
    └── start-tis-pipeline.sh      # Pulls config, starts pipeline
```

## What Runs on EC2

| Process | Description | Systemd Service |
|---------|-------------|-----------------|
| TIS Pipeline | Price fetcher + condition evaluator + webhook receiver + enrichment + SQS publish | `tis-pipeline.service` |

The pipeline is a single Python process running the async event loop with:
- Price fetcher polling BDS `get_snapshot` every 5s
- Condition evaluator checking conditions on each price update
- FastAPI webhook receiver (Uvicorn) on port 8080
- Enrichment layer querying BDS for positions/orders
- SQS publisher sending enriched TriggerEvents to the trigger-events queue

## Dependencies

- **ADF-005** — BDS deployed on EC2 (provides get_snapshot, get_positions, get_open_orders)

- [ ] Create production `config/tis.yaml` with correct SQS queue URL, BDS endpoints
- [ ] Create `scripts/install-tis-services.sh` — copies unit to systemd, enables and starts
