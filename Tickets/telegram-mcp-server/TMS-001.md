## Summary

Build the standalone `telegram-mcp-server` — a thin, stateless FastMCP + stdio wrapper around the Telegram Bot API, exposing five tools: `send_message`, `send_alert`, `get_updates`, `edit_message`, `send_photo`. Follows the patterns already established by `coingecko-scanner` and `ftp-agent`.

## Spec ambiguity surfaced and resolved

The documented alert format `{key}: {value}` / `→ {suggested_action}` is not invertible for arbitrary inputs. Resolution: documented detail-key preconditions (no `": "` substring, no `"→ "` prefix) in `format_alert`'s docstring; Property 1 test generator respects them. See [[telegram-mcp-server/Technical Notes]] → Open questions.
