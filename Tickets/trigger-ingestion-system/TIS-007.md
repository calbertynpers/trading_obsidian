# TIS-007: Pine Script Alert Integration — Chart-Driven Trigger Source

**Priority:** Medium
**Status:** 🔴 Open
**Component:** `trigger_ingestion_system` — external trigger path extension
**Type:** Feature
**Reported:** 2026-04-26
**Depends On:** [[TIS-003]], [[IDS-002]]

---

## Summary

Extend the TIS external trigger path to natively support webhook alerts fired by agent-generated Pine Script indicators. Pine Script alerts originate from TV chart-level indicators rather than manually authored TV alerts, and carry structured metadata specific to the Pine Script format — price level context, setup type, level label, and distance from trigger. This ticket defines the payload contract, TriggerEvent mapping, and agent prompt construction for Pine Script-sourced alerts.

---

## Context

The existing TIS external trigger path (TIS-003) handles generic TradingView webhook alerts where the message field is authored manually by the trader. Pine Script-generated alerts introduce a new, structured sub-type: the Pine Script indicator is generated by the agent (see IDS-002), drawn on the user's TV chart, and simultaneously wired with `alertcondition()` blocks that fire webhooks when price interacts with key levels.

This is the **closed loop**:

```
Agent generates Pine Script
        ↓
User pastes indicator to TV chart
        ↓
Chart renders: S/R lines, entry zones, TP/SL labels
        ↓
Price hits a level → Pine Script alertcondition fires
        ↓
TV POSTs webhook to TIS /webhook endpoint
        ↓
TIS parses Pine Script payload → TriggerEvent
        ↓
Agent evaluates (with enriched position context)
        ↓
Telegram: inform or propose
```

The same Pine Script serves as both the visual chart annotation and the agentic tripwire.

---

## Pine Script Webhook Payload Format

Agent-generated Pine Scripts shall emit structured JSON webhook payloads:

```json
{
  "passphrase": "${WEBHOOK_PASSPHRASE}",
  "symbol": "TAOUSDT",
  "source": "pine_script",
  "setup_id": "taousdt-ftp-20260426",
  "level_label": "resistance_1",
  "level_price": 260.00,
  "trigger_price": "{{close}}",
  "level_type": "resistance",
  "setup_type": "ftp",
  "urgency": "alert",
  "message": "TAOUSDT has touched resistance at 260.00. FTP setup active — monitor for rejection confirmation before shorting.",
  "direction": "short"
}
```

**Field definitions:**

| Field | Type | Description |
|-------|------|-------------|
| `passphrase` | str | Shared secret — same as standard TV webhooks |
| `symbol` | str | Trading pair |
| `source` | str | Always `"pine_script"` — distinguishes from manual TV alerts |
| `setup_id` | str | Unique ID for the generated setup — links back to the originating script |
| `level_label` | str | Human label for the triggered level (e.g. `resistance_1`, `entry_zone`, `stop_loss`) |
| `level_price` | float | The price level that was touched |
| `trigger_price` | str | TV dynamic field — actual close price at alert fire time |
| `level_type` | str | `resistance`, `support`, `entry`, `stop`, `take_profit` |
| `setup_type` | str | `ftp`, `mean_reversion`, `breakout`, `sr_map` |
| `urgency` | str | `info`, `alert`, `action_required` |
| `message` | str | Agent prompt — pre-authored in the Pine Script, passed through as instruction |
| `direction` | str | `long`, `short`, `neutral` |

## TriggerEvent Mapping

Pine Script alerts map to TriggerEvent with `source: "pine_script"` (requires new Literal value in TriggerEvent schema — coordinate with TIS-001/TIS-002):

```python
TriggerEvent(
    trigger_id=uuid4(),
    source="pine_script",
    trigger_type="chart_level_touch",
    symbol=payload["symbol"],
    timestamp=now_iso8601(),
    urgency=payload["urgency"],
    message=payload["message"],        # pre-authored agent prompt from Pine Script
    raw_payload=payload,
    context={},                        # populated by Enrichment_Layer
    suggested_action=payload.get("direction")
)
```

## Agent Prompt Construction

For Pine Script triggers, the message field is pre-authored in the indicator at generation time — the same pattern as manual TV alerts acting as agent prompts. No additional prompt construction is required beyond appending enriched context.

Example agent prompt delivered to Agent_Session:

```
TAOUSDT has touched resistance at 260.00. FTP setup active — monitor for rejection confirmation before shorting.

--- Position Context ---
Side: LONG | Size: 10 units | Entry: $246.72 | Mark: $260.10
Unrealised PnL: +$133.80 (+5.42%)
Open orders: STOP_MARKET SELL 5 @ $225.00, STOP_MARKET SELL 2.5 @ $168.00
```
