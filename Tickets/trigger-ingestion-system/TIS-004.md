## Summary

Build the generic SQS publisher module and extend the TIS configuration with the queue URL. This is a reusable utility that any source process can import to publish enriched TriggerEvents (or any Pydantic model) to SQS.

## Scope

- `trigger_ingestion/sqs_publisher.py` — Generic publisher: serialise Pydantic model → SQS
- `trigger_ingestion/config.py` — Extend with `sqs_queue_url` field
- `config/tis.yaml` — Add `sqs.queue_url` placeholder
- `tests/test_sqs_publisher.py` — Unit tests (moto for SQS mocking)
- `tests/test_config.py` — Extend with sqs_queue_url tests

## Key Design Decisions

- boto3 + `asyncio.to_thread()` for non-blocking SQS from async event loop
- Never raises — returns True/False. Caller decides how to handle failure.
- Accepts any Pydantic BaseModel (not just TriggerEvent) — reusable
- FIFO params (group_id, dedup_id) optional — standard queue for now, FIFO-ready interface

## Acceptance Criteria

- [ ] SQSPublisher serialises any Pydantic model to JSON and publishes to SQS
- [ ] Publish failure returns False without raising (caller process doesn't crash)
- [ ] Config loads `sqs_queue_url` from YAML with env var resolution
- [ ] Missing/empty `sqs_queue_url` raises ValueError at startup
- [ ] Round-trip: serialise → deserialise produces equivalent model
