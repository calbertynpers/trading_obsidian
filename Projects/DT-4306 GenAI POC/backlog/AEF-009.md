# AEF-009: Improvement Analysis Engine

## Summary

Automatically analyse eval run failures, group them by dimension and pattern, and map them to actionable categories (prompt fix, tool description fix, tool extension, tool addition, ground truth fix). Rank by frequency so the highest-impact improvements are addressed first.

## When to Pick Up

When the team is running evals independently and needs automated guidance on what to fix next. In early stages, you'll know from the score cards what's failing — this automates that analysis.

## Scope

- ImprovementAnalyser: takes an EvalRun, produces ranked FailurePatterns
- Failure pattern grouping by eval dimension
- Mapping to actionable categories with frequency ranking
- Output as part of run summary
- Property-based test for analysis correctness

R15: Iterative Improvement Loop (all 3 ACs)
