# AEF-005: Result Visualisation Dashboard

## Summary

Build an interactive Marimo dashboard for eval results: overall pass rates, per-dimension breakdowns, per-category breakdowns, drill-down from failed test cases to full transcripts, and cross-run comparison to identify regressions or improvements.

## When to Pick Up

After 3-4 eval runs when there's enough data to make comparison meaningful. The MVP's printed summary table becomes insufficient when you need to spot patterns across runs.

## Scope

- Summary dashboard: overall pass rate, per-dimension, per-category, Pass@K (if AEF-004 done)
- Per-test-case breakdown with pass/fail heatmap across dimensions
- Drill-down: click a failed test case → see full transcript + score card
- Cross-run comparison: select two runs, see what improved/regressed
- Marimo reactive cells for filtering and exploration

## Requirements Covered

R14: Result Visualisation (all 4 ACs)
