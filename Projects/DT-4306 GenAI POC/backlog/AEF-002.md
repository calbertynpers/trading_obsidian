# AEF-002: MVP Eval Framework — Complete Eval Loop

## Summary

Implement the minimum viable evaluation framework: define test cases, send questions to the agent, capture transcripts, grade them automatically (code graders + one model grader), persist results, and display a summary. This is the core eval loop that enables iterative quality improvement.

## Goal

A developer can run the full test library against the agent from a Marimo notebook, see a pass/fail summary across all eval dimensions, and save results to disk for comparison after making changes.

## Sub-Tickets (Iterative Delivery)

### AEF-002a: Core Data Models + Test Case Library + Seed Cases
- Python dataclasses: TestCase, GroundTruth, Transcript, ToolCall, ScoreCard, GradeResult
- JSON serialization/deserialization
- TestLibrary loader with basic validation (dataclass type hints, not full JSON Schema)
- 3-5 seed test cases (2 in-scope happy path, 1 out-of-scope) to validate the structure
- Data snapshot metadata file
- **Delivers:** You can define, load, and inspect test cases programmatically

### AEF-002b: Agent Client + Transcript Capture + Basic Notebook
- LocalAgentClient that calls the agent and returns structured Transcripts
- Wire up: question → agent → Transcript with all tool calls, params, responses, timing
- Basic Marimo notebook: send a single question, display the transcript
- **Delivers:** You can send any question and see exactly what the agent did. Useful for debugging even without grading.

### AEF-002c: Code Graders + Grader Pipeline
- SequenceComplianceGrader, ToolSelectionGrader, ToolCallCorrectnessGrader, OutOfScopeCodeGrader
- GraderPipeline orchestrator with dimension applicability logic
- Property-based tests (Hypothesis) for all code graders + score card aggregation + dimension applicability
- **Delivers:** Automatic structural grading. Run a question, get pass/fail on sequence, tool selection, parameter correctness, OOS compliance.

### AEF-002d: Response Quality Model Grader
- ModelGrader base class with Claude API integration
- ResponseQualityGrader with hardcoded rubric (accuracy, completeness, formatting, faithfulness)
- Add to GraderPipeline execution order
- **Delivers:** Full grading pipeline — code graders catch structural issues, Claude catches quality issues.

### AEF-002e: Eval Runner + Result Persistence + Test Corpus Buildout
- EvalRunner: batch execution (load cases → run trials → grade → persist)
- Basic ResultStore: save transcripts + score cards + run summary as JSON files
- Expand test library to 15-20 cases across all 8 categories, all 3 difficulty tiers
- Marimo notebook: select test cases → run eval → print pass/fail summary table → save results
- **Delivers:** The complete MVP loop.
