# AEF-003: Data Interpretation Model Grader

## Summary

Add a dedicated LLM-as-judge grader that evaluates whether the agent correctly interpreted raw tool data — unit conversions (meters→km, seconds→hours), rankings, filtering, and aggregation. This is more granular than the response quality grader and catches specific numerical errors.

## When to Pick Up

After MVP reveals that data interpretation errors (wrong numbers, incorrect rankings, missed unit conversions) are a common failure mode that the response quality grader isn't catching with enough specificity.

## Scope

- DataInterpretationGrader implementation with rubric focused on comparing agent's stated conclusions against raw tool data
- Rubric covers: numerical correctness, ranking/ordering correctness, filtering correctness, completeness
- Integration into GraderPipeline (runs after code graders, before response quality)
- Test cases with known data interpretation challenges (e.g., mileage in meters that should be displayed in km)

## Requirements Covered

R7: Data Interpretation Grading (all 4 ACs)
