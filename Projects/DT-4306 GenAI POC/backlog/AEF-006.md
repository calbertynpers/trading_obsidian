# AEF-006: Human Grading Interface

## Summary

Build a Marimo UI for team members to review agent transcripts and provide pass/fail judgments with annotations alongside automated scoring. Human grading calibrates the model graders and catches issues automated checks miss.

## When to Pick Up

When the team is regularly running evals and wants to validate that automated grading aligns with human judgment. Also useful for calibrating model grader rubrics.

## Scope

- Transcript viewer in Marimo: question, tool calls with params/responses, final response
- Per-dimension pass/fail input controls
- Free-text annotation fields
- Human score cards stored alongside automated score cards in ResultStore
- Linked by trial ID for comparison
