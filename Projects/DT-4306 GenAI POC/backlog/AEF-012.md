# AEF-012: Guardrails / Topic Restriction Eval Dimension

## Summary

Add a new eval dimension that verifies the agent declines questions entirely outside the fleet management domain (politics, general knowledge, personal advice). This is distinct from out-of-scope handling (which covers fleet questions the tools can't answer) — this covers "not a fleet question at all."

## When to Pick Up

When the agent is being prepared for customer-facing deployment and needs to handle arbitrary user input safely.

## Scope

- New eval dimension: `guardrails_compliance`
- Test cases with off-topic questions (politics, general knowledge, personal advice, harmful content)
- Ground truth: no tools called, response redirects to fleet management capabilities
- Code grader: verify no tools called
- Model grader: verify response appropriately declines and redirects
- Distinct from `out_of_scope_handling`: that covers "fleet question, wrong tools"; this covers "not a fleet question"
