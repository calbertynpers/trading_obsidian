# AEF-004: Multi-Trial Reliability (Pass@K)

## Summary

Add support for running each test case K times and computing Pass@K metrics to distinguish between consistent failures ("never works") and intermittent issues ("sometimes works"). This is critical for tuning prompts where non-deterministic LLM behaviour means a single trial isn't representative.

## When to Pick Up

When iterating on prompts and seeing inconsistent results between eval runs — the same test case passes sometimes and fails other times.

## Scope

- K parameter on EvalRunner (default K=3)
- Pass@K computation: proportion of test cases where at least 1 of K trials passes all graders
- Pass@K reported in run summary alongside per-trial pass rates
- Property-based test for Pass@K computation correctness

## Requirements Covered

R13: Reliability Metrics (all 3 ACs)
