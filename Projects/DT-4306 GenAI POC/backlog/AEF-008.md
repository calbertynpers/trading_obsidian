# AEF-008: Rubric Template Management

## Summary

Extract model grader rubric prompts from hardcoded strings into versioned template files with placeholder variables. This enables iterating on grading criteria independently of the evaluation harness code.

## When to Pick Up

When you find yourself frequently editing rubric prompts and wanting to track changes. Also useful when rubric modifications should be captured in config snapshots (pairs with AEF-007).

## Scope

- Rubric template files (markdown) in `eval/rubrics/` — one per model-graded dimension
- Placeholder variables for transcript content and ground truth
- ModelGrader loads rubrics from templates at runtime
- Rubric changes treated as config changes (captured in snapshots if AEF-007 done)

## Requirements Covered

R17: Grader Rubric Management (all 3 ACs)
