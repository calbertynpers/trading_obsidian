# AEF-010: Remote Agent Support (EC2)

## Summary

Add a RemoteAgentClient that connects to the deployed agent on EC2 via HTTP, enabling eval runs against the production-like environment rather than just local development.

## When to Pick Up

When the Streamlit demo is deployed to EC2 and you want to verify that the deployed agent behaves the same as the local one. Also needed before any stakeholder-facing eval results.

## Scope

- RemoteAgentClient: HTTP POST to agent endpoint, parse response into Transcript
- Health check endpoint support
- Auth token support (if EC2 endpoint requires authentication)
- Configurable timeout with retry logic
- Agent endpoint URL as configurable parameter in Marimo notebook

## Requirements Covered

R3 AC6: Support connecting to both local and remote agent instances
