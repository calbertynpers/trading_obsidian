# AEF-007: Configuration Snapshots & Cross-Model Benchmarking

## Summary

Capture the full configuration state (system prompt, tool descriptions, model provider/version, temperature, rubrics) with each eval run so results are reproducible and attributable. Support diffing configs between runs to identify what changed.

## When to Pick Up

When comparing results across different LLM providers (Claude vs Bedrock) or when multiple team members are making changes and you need to track what caused a regression.

## Scope

- ConfigSnapshot dataclass: system prompt, tool descriptions, tool filter config, model provider, model version, temperature, max tokens, provider-specific config, rubric hashes
- Snapshot captured and persisted at start of each eval run
- Config diff between two runs (changed fields, added/removed)
- Display diff in Marimo notebook
- Property-based test for config diff correctness

## Requirements Covered

R16: Configuration Snapshot and Reproducibility (all 4 ACs)
