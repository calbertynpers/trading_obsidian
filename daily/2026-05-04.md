### Decisions / lessons
- **Placeholder-then-populate** beats `--parameter-overrides`: secret material never touches CloudFormation event history or shell history.
- **CFN replaces SecretsManager secrets without a recovery window** when `Name` changes — caught me out during the path-scheme migration. Capture values via `get-secret-value` before any rename.
- **`return` from inside a function does NOT exit a sourced bash script** — it only exits the function. Use a top-level `${__HALT}` variable holding `exit` or `return` and invoke inline at each failure point. Initial pull-secrets.sh had this bug; fixed and verified.
